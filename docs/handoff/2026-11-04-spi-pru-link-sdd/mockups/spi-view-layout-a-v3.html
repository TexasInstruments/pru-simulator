What the datasheet does and doesn't give: for direct output mode it specifies only GPO-to-GPO skew (max 2 ns, with 2–30 pF load and 1–3 V/ns input slew). It has no timing table for direct input mode, so input setup and hold are design budgets, not datasheet limits. In those budgets, "sample" is the 1-core-cycle uncertainty of polling R31 (5 ns at 200 MHz, 3 ns at 333 MHz). For reference only (not used in direct mode): the parallel-capture mode requires tsu ≥ 4 ns and th ≥ 0 ns (Table 6-114).
