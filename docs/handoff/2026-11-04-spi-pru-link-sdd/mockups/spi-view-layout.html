SPI view under I/O & Devices: which layout feels right?

Each option shows the same READ/WRITE frame (cmd 0x03, address 0x02 → byte 32, idle, 16 data bytes) in SPI mode 1, 25 MHz on a 200 MHz core. The waveform is a sketch: the real one comes from the simulator's pin trace.
