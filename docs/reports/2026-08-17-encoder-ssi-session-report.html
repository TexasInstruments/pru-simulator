1 Project Overview

Implementation of complete SSI encoder simulator support for 12-bit absolute encoder validation. Includes PRU0 reader firmware, PRU1 emulator firmwares (fixed-value and sequence), MCP injection tool, and automated regression tests.

2 Implementation Details

2.1 SSI Reader Firmware

Location: source/ssi_reader_4mhz_12bit/ssi_reader_4mhz_12bit.asm

PRU0 assembly firmware that generates a 4 MHz SSI clock and captures 12-bit absolute encoder position MSB-first. Key features:

  • Exact 300 MHz core clock requirement for 4 MHz SSI (75 cycles/bit)
  • Symmetric clock timing: HIGH_DLY=33, LOW_DLY=35 cycles
  • Monoflop pause: 12.5 µs minimum via nested loop (15×250 cycles)
  • Captures data on rising clock edge, MSB-first shifting
  • Stores 32-bit result (12-bit position zero-extended) to DRAM0 offset 0x10
  • Frame counter maintained in R20 register

2.2 Fixed-Value SSI Emulator

Location: source/ssi_encoder_emulator_12bit/ssi_encoder_emulator_12bit.asm

PRU1 assembly firmware that emulates a fixed 12-bit SSI encoder value. Key features:

  • Purely reactive to external SSI clock (no clock generation)
  • Uses wbc/wbs instructions for edge detection
  • Default value: 0xA5A (stored in DRAM1 offset 0x08)
    • DRAM1 offset 0x14: frame counter increments per frame
  • Sync-detection loop prevents false triggering (PAUSE_THRESH=300)
  • Drives MSB-first data on falling clock edges

2.3 Sequence SSI Emulator

Location: source/ssi_encoder_sequence_emulator_12bit/ssi_encoder_sequence_emulator_12bit.asm

PRU1 assembly firmware that cycles through a predefined test sequence. Key features:

  • Same reactive design as fixed-value emulator
  • Test sequence: 0xABC → 0xAAA → 0xBCA → 0x12A → 0xCC2 → repeat
  • Each value held for one complete frame
  • Frame counter serves as sequence index (DRAM1 offset 0x14)
  • Current value readable at DRAM1 offset 0x08
  • Low PAUSE_THRESH=1 for fast initial synchronization

2.4 MCP Injection Tool

Location: mcp_server/simulator_mcp.py

Extended with pru_ssi_inject method for single-core validation. Features:

  • Attaches SSIEncoderEdgeModel to simulator IO port
  • Drives correct MSB-first bit sequence in response to clock transitions
  • Returns validation data: {expected, captured, match, frames_captured, cycle_count}
  • Eliminates need for PRU1 emulator during development/testing
  • Validated for test values 0x000, 0xA5A, 0xFFF

2.5 Automated Regression Test

Location: tests/test_ssi_encoder_sequence_emulator.py

End-to-end validation test that:

  • Loads SSI reader on PRU0 and sequence emulator on PRU1
  • Wires GPIO loopback: PRU0 GPO0→PRU1 GPI16 (clock), PRU1 GPO0→PRU0 GPI8 (data)
  • Runs paced multi-core execution
  • Verifies PRU0 captures sequence values in order at DRAM0 offset 0x10
  • Confirms both frame counters advance correctly
  • Reports PASS when all five sequence values validated

3 Validation Methods

3.1 Automated Testing

The implementation includes an automated regression test that validates the complete SSI encoder chain:

python -m pytest tests/test_ssi_encoder_sequence_emulator.py -v

This test executes in approximately 0.7 seconds and validates all five sequence values (0xABC, 0xAAA, 0xBCA, 0x12A, 0xCC2) are correctly captured by the reader.

3.2 Manual UI Validation

Validation using the browser-based simulator dashboard:

  1. Start dashboard: python ui/server.py
  2. Load SSI reader on PRU0
  3. Load sequence emulator on PRU1
  4. Configure GPIO loopback:
    • PRU0 GPO0 (clock out) → PRU1 GPI16 (clock in)
    • PRU1 GPO0 (data out) → PRU0 GPI8 (data in)
  5. Enable Signal Graph recording
  6. Run multi-core execution
  7. Observe clean 12-clock SSI transitions in both clock lanes
  8. Use "Fit frame" to zoom to newest complete SSI frame
  9. Verify DRAM0 offset 0x10 matches expected sequence value
  10. Check frame counters increment on both cores

3.3 Single-Core Validation via MCP

Quick validation without requiring PRU1 emulator:

python3 -c " from mcp_server.simulator_mcp import PRUSimulatorMCP mcp = PRUSimulatorMCP() result = mcp.pru_ssi_inject( source=open('source/ssi_reader_4mhz_12bit/ssi_reader_4mhz_12bit.asm').read(), value=0xABC, clk_pin='GPO0', data_pin='GPI8' ) print(f'Expected: 0x{result[\"expected\"]:03X}') print(f'Captured: 0x{result[\"captured\"]:03X}') print(f'Match: {result[\"match\"]}') print(f'Frames: {result[\"frames_captured\"]}') "

Should return match=true for test values 0x000, 0xA5A, and 0xFFF.

6 Usage Instructions

6.1 Multi-Core Validation (Recommended)

For complete end-to-end validation:

  1. Start simulator dashboard: python ui/server.py
  2. Load ssi_reader_4mhz_12bit.asm on PRU0
  3. Load either emulator on PRU1:
    • ssi_encoder_emulator_12bit.asm (fixed value 0xA5A)
    • ssi_encoder_sequence_emulator_12bit.asm (cycling test sequence)
  4. Configure GPIO loopback in IO panel:
    • PRU0 GPO0 → PRU1 GPI16 (clock)
    • PRU1 GPO0 → PRU0 GPI8 (data)
  5. Enable Signal Graph recording
  6. Click Run in multi-core mode
  7. Monitor results:
    • DRAM0 offset 0x10 on PRU0: captured position
    • Frame counters on both cores (R20 for PRU0, DRAM1 0x14 for PRU1)
    • Signal Graph shows clean 12-clock transitions

6.2 Single-Core Validation

For quick reader validation without PRU1:

  1. Load ssi_reader_4mhz_12bit.asm on PRU0 only
  2. Open SSI Encoder Inject panel in UI
  3. Enter 12-bit hex value (e.g. ABC)
  4. Select pins GPO0 (clock) and GPI8 (data)
  5. Click Inject
  6. Click Run
  7. Check DRAM0 offset 0x10 for result

6.3 MCP Server Validation

Programmatic validation via Python:

from mcp_server.simulator_mcp import PRUSimulatorMCP mcp = PRUSimulatorMCP() result = mcp.pru_ssi_inject( source=open("source/ssi_reader_4mhz_12bit/ssi_reader_4mhz_12bit.asm").read(), value=0xABC, clk_pin="GPO0", data_pin="GPI8" ) # Returns: {expected: 0xABC, captured: 0xABC, match: true, frames_captured: 1, cycle_count: ...}

6.4 Automated Regression Test

Run the complete validation suite:

python -m pytest tests/test_ssi_encoder_sequence_emulator.py -v
