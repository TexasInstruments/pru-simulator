2 Scope

This task integrates the accepted timestamped producer with the simulator SSIRuntime, implements the PRU0 ring consumer and request-time estimator, initializes the shared 300 MHz IEP from PRU1, and keeps the simulator, CCS sources, UI, and MCP controls aligned.

3 Implemented Behavior

Implemented in this session

3.1

Coherent single-read producer head, no ring scan

PRU0 reads a coherent producer head and exactly the latest sample and predecessor; it never scans the 256-entry ring.

3.2

Estimator work moved to idle time, falling edge kept minimal

Ring reads, period/age/horizon checks, signed estimate arithmetic, and prepared-frame publication run during idle tm. The falling edge only captures IEP COUNT_LO plus latched COUNT_HI before entering the existing bit loop.

3.3

PRU1 initializes the shared IEP0 at 300 MHz

PRU1 selects the OCP clock through c4 + 0x30 and enables IEP0 through c26 + 0x00 with 0x11, giving one IEP tick per 300 MHz PRU cycle.

3.4

Static mode stays default; timestamped mode adds bounded dynamic packing

Static mode remains the default and preserves prepacked 1..64-bit frames. Timestamped mode supports binary or reflected Gray, integer positions up to 31 bits, explicit/right-aligned placement, zero padding, and 1..64-bit raw frames. Metadata absent from the sample ABI is rejected explicitly and the last frame is held.

3.5

Fault paths hold the last frame; PRU0 stops touching the producer head

Stale, horizon, generation, coherence, overflow, missed-preparation, and ring-overrun paths retain the last prepared frame. PRU0 no longer rewrites the producer-owned head while publishing diagnostics.
