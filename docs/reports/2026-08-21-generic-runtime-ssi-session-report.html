Generic runtime-configurable SSI

Simulator contract and parent CCS alignment updated

Scope

The generic SSI loopback now uses PRU0 as the reactive encoder emulator and PRU1 as the clock-generating reader/master. The simulator UI, runtime API, MCP surface, and parent AM243x project use the same shared-memory ABI and wiring convention.

Implemented behavior

  • 1..64-bit frames, two-word accumulation, structural position/status extraction, seqlock mailbox publication, and a 1024-record trace ring.
  • Host-side named profiles, staged validation, binary/Gray/ Gray-excess/Tannenbaum packing, alignment, padding, status fields, and overflow rejection.
  • Frame-count/time holds, synchronous formation gating, all eight fault modes, finite fault recovery, reader-only mode, and idle-boundary generation switching.
  • Dashboard controls for semantic positions, optional Gray-excess metadata, timing, capture, faults, Stage, Apply, Run, and readback.
  • Deterministic 15-cycle reader overhead accounting, balanced data-level timing, active-versus-staged semantic readback, and `tv < sample < high` validation.
  • End-to-end coverage for all 13 named profiles, including the synchronous Tannenbaum profile and the 64-bit boundary cases.
  • Parent CCS project sources for PRU0 emulator, PRU1 reader, generated ABI snapshots, R5 apply/packing, mailbox access, and UART commands.
