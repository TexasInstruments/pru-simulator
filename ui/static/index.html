        PRU0 · open-loop V/f · PMSM plant model

        Motor control

        Open-loop V/f control on PRU0: the firmware ramps the speed, integrates the electrical angle and drives three PWM pins; the PMSM model sees only those pins and returns phase current as PDM on GPI3/GPI4. Angles, duties and currents below are measured from the pins and the plant.

        Firmware not loaded.

        Setup

        Attaches the foc_motor profile on PRU0 if needed and loads source/foc_open_loop.asm. Use Start to run it.

        References

        Voltages are per unit of the DC bus; the linear limit is 0.577. Apply changes take effect at the next control update of a running firmware.

        Motor physics

        Applied live to the plant from its next step. Flux 0 makes it a plain three-phase RL load. Invalid values change nothing.
