        →Step — execute one instruction
        ←Step Back — reverse one instruction
        SpaceToggle breakpoint at current PC
        ?Open / close this help window
        EscClose open modal (help, config)
        Controls
        StepExecute one instruction
        Step BackReverse the last instruction — full machine state (registers, memory, SD filter) restored
        RunToggle continuous execution
        SIMToggle timed simulation mode
        ResetSoft reset — registers and PC to 0
        HW ResetHard reset — clears SPAD and XFR config
        Multi-coreToggle dual-core (PRU0 + RTU0) debug view
        ConfigEdit simulator configuration (JSON)
        ⊞ Reset LayoutRestore default panel layout
        Assembly Editor
        OpenLoad a .asm/.inc file from the server, or browse for any file (.asm, .out)
        Open .outBrowse for a compiled PRU ELF binary — loads and disassembles automatically
        ProjectOpen a project folder — all files open as tabs in manifest order
        SaveSave the active tab to disk
        Load & AssembleAuto-save all tabs, assemble, and load into PRU; project files concatenated in manifest order
        Registers Panel
        C-TableShow / hide the PRU constant table (C0–C31)
        SPAD: B0 B1 B2Toggle Scratch-Pad Bank 0/1/2 columns alongside registers (XFR device 10/11/12)
        SPAD: IPCToggle IPC_SP scratch-pad columns R2–R9 (XFR device 15)
        XFR: SHFToggle XFR_SHIFT_EN bit (ICSSG_SPP_REG[1])
        Carry / MAC rowShows Carry flag; in MAC mode also shows MAC mode (MPY/MAC/ACC) and carry state
        Click register valueEdit the value inline — press Enter or click away to commit
        IO Panel
        GPO pinsLive R30 bit indicators — updated every step
        Loopback stripFive toggle buttons between GPO and GPI rows; each wires a 4-bit group (3:0, 7:4, …) of GPO directly to GPI combinatorially
        GPI pinsR31 bit indicators — click any pin to drive it high/low when SD is disabled
        ▶ DecodeUART decode of recorded GPO0 transitions (8N1, auto-detect baud); shows hex + ASCII bytes
        ClearClear UART decode output
        SD panelAppears when firmware sets sd_en (R30 bit 25); shows R30 decode bar, per-channel CIC accumulator values, pattern generator controls, and OSR config chips

        LSB / MSBToggle byte order
